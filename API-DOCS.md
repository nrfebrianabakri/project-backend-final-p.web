Beberapa api documentation:
1. untuk melihat healt atau aplikasi normal aktif, menggunakan GET http://52.23.111.229:3000/api/ (bisa ADMIN/USER)
![health](<img/Screenshot 2025-12-14 at 23.35.38.png>)
2. untuk login, menggunakan POST http://52.23.111.229:3000/api/auth/login (bisa ADMIN/USER)
![login](<img/Screenshot 2025-12-14 at 23.36.43.png>)
3. untuk lihat daftar buku, menggunakan GET http://52.23.111.229:3000/api/books (bisa ADMIN/USER)
![lihat daftar buku](<img/Screenshot 2025-12-14 at 23.37.34.png>)
4. untuk lihat detail buku, menggunakan GET http://52.23.111.229:3000/api/books/id (bisa ADMIN/USER)
![lihat detail buku](<img/Screenshot 2025-12-14 at 23.37.46.png>)
5. untuk hapus data buku, menggunakan DELETE http://52.23.111.229:3000/api/books/id (hanya ADMIN)
![hapus data buku](<img/Screenshot 2025-12-14 at 23.39.46.png>)
6. untuk tambah data buku, menggunakan POST http://52.23.111.229:3000/api/books (hanya ADMIN)
![tambah buku](<img/Screenshot 2025-12-14 at 23.43.01.png>)
7. untuk lihat detail informsi akun sendiri, menggunakan GET http://52.23.111.229:3000/api/auth/me (bisa ADMIN/USER)
![lihat informasi akun sendiri](<img/Screenshot 2025-12-14 at 23.43.30.png>)
8. untuk lihat daftar kategori, menggunakan GET http://52.23.111.229:3000/api/categories (bisa ADMIN/USER)
![lihat daftar kategori](<img/Screenshot 2025-12-14 at 23.43.55.png>)
9. untuk lihat daftar peminjaman, menggunakan GET http://52.23.111.229:3000/api/laons (hanya ADMIN)
![lihat dafttar yang meminjam](<img/Screenshot 2025-12-14 at 23.44.13.png>)
